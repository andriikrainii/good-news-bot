# 🌻 Бот добрих новин і шкільних тестів

Бот кілька разів на день сам надсилає у ваш Telegram-чат добрі новини
з усього світу — українською, з картинкою й посиланням на джерело.

А ще він влаштовує родині невеликі тести зі шкільної програми —
географія, математика, історія, біологія, українська мова. Питання
приходить із варіантами відповіді, кожен тисне свій, і Telegram одразу
показує, хто вгадав. Детальніше — у розділі [🎓 Шкільні тести](#-шкільні-тести-для-родини).

Він працює на серверах GitHub, а **не** на вашому комп'ютері.
Тобто новини приходитимуть навіть тоді, коли у вас немає світла
чи інтернету, і комп'ютер узагалі вимкнений.

## Як змінити налаштування (з телефона теж)

Усе, що можна міняти, лежить в одному файлі — **`config.yaml`**.

1. Відкрийте цей репозиторій на GitHub.
2. Натисніть на файл **`config.yaml`**.
3. Натисніть **олівець** (✏️) угорі праворуч.
4. Змініть, що треба.
5. Прокрутіть униз і натисніть зелену кнопку **Commit changes**.

Усе. Наступного разу бот працюватиме вже за новими правилами.

> ⚠️ Одне важливе правило: **не міняйте пробіли на початку рядків.**
> Міняйте лише самі значення. Якщо файл випадково зламався —
> натисніть на нього, далі **History**, і поверніться до попередньої версії.

### Скільки новин на день

Знайдіть рядок:

```yaml
posts_per_day: 5
```

Поставте будь-яке число. Наприклад `3` — і на день приходитиме три новини.
Вони розділяться між часами розсилки якомога рівніше:
5 новин на 3 часи — це 2, 2 і 1.

### О котрій приходять новини

```yaml
send_times:
  - "09:00"
  - "14:00"
  - "20:00"
```

Час київський. Можна змінити години, додати ще один рядок або прибрати зайвий.
Головне — зберігати такий самий вигляд рядка: два пробіли, дефіс, пробіл і час у лапках.

### Які теми новин

Нижче у файлі є список тем. У кожної є рядок `enabled`:

```yaml
  - name: "Космос"
    enabled: false
```

- `true` — тема **увімкнена**, новини на цю тему приходитимуть;
- `false` — тема **вимкнена**.

Щоб увімкнути космос — просто замініть `false` на `true`.

Увімкнено від початку: наука і медицина, природа і тварини,
люди й добрі вчинки, технології та екологія.
Вимкнено: культура і спорт, космос.

### Стоп-слова

Список `blocked_keywords` — це слова-запобіжники. Якщо якесь із них є в новині,
бот її не надішле. Там уже є все про війну, політику, смерть і катастрофи.
Можна додавати свої слова — англійською, бо новини беруться з англомовних сайтів.

## 🎓 Шкільні тести для родини

Бот надсилає в чат питання зі шкільної програми — таке собі родинне
«Хто розумніший?»:

> 🌍 **Географія · 1–4 клас**
> Яка столиця Єгипту?
> ◦ Луксор  ◦ Каїр  ◦ Асуан  ◦ Александрія

Кожен у групі тисне свій варіант, і Telegram одразу показує, правильно
це чи ні, та лічить, хто як відповів. Боту нічого рахувати не треба —
усе робить сам Telegram. До багатьох питань є коротке пояснення: воно
з'являється після відповіді, якщо натиснути на лампочку 💡.

Зараз у боті **206 питань** із п'яти предметів. Варіанти відповіді бот
щоразу перемішує, тож «тисну перший» не спрацює. Одне й те саме питання
не повториться, поки не закінчаться всі інші.

### Налаштування тестів

Усе в тому ж `config.yaml`, у розділі `quiz`:

```yaml
quiz:
  enabled: true          # false — тести не приходитимуть зовсім
  per_day: 3             # скільки тестів на добу
  send_times:            # о котрій (час київський)
    - "16:00"
    - "19:30"
  levels:                # 1 — 1-4 клас, 2 — 5-7 клас, 3 — 8-11 клас
    - 1
    - 2
    - 3
  show_who_answers: true # видно, хто як відповів
  time_limit_seconds: 0  # 0 — думати можна скільки завгодно
  subjects:
    - name: "Географія"
      enabled: true
    ...
```

Кілька підказок:

- **Малі діти в чаті?** Залиште в `levels` тільки `1` (і, може, `2`) —
  питання стануть простішими.
- **Хочете змагання на швидкість?** Поставте `time_limit_seconds: 60` —
  Telegram покаже таймер і сам закриє питання, коли час вийде.
- **Не хочете, щоб було видно, хто помилився?** Поставте
  `show_who_answers: false` — відповіді стануть анонімними.
- **Забагато тестів?** Зменшіть `per_day` або приберіть один час
  із `send_times`.

### Чи треба щось робити руками

Ні. Тести працюють так само автономно, як і новини:

1. **Netlify** цілодобово стежить за годинником і, коли настає 16:00
   або 19:30, просить GitHub запустити бота. Якщо Netlify мовчить —
   GitHub усе одно прокидається сам тричі на годину.
2. **GitHub** запускає бота, той дивиться, чи є невідпрацьований час
   за сьогодні, бере питання й надсилає його в чат.
3. **Telegram** приймає відповіді, показує правильну й лічить, хто
   як відповів — тут бот уже не потрібен.
4. **Пам'ять** (`state.json`) записується назад у репозиторій, щоб
   питання не повторилося й тест не пішов двічі.

Комп'ютер вмикати не треба, ключів і грошей тести не потребують
(на відміну від перекладу новин — там потрібен ключ Anthropic).

Питань вистачає приблизно на **два місяці** по три тести на день.
Коли всі 206 закінчаться, бот почне коло спочатку — питання підуть
у новому порядку й з перемішаними варіантами.

### Як додати свої питання

Питання лежать у папці `questions/` — по файлу на предмет:
`geography.yaml`, `math.yaml`, `history.yaml`, `biology.yaml`,
`ukrainian.yaml`. Файли можна редагувати з телефона так само, як
`config.yaml`: відкрити на GitHub → олівець → змінити → **Commit changes**.

Одне питання виглядає так:

```yaml
  - q: "Яка столиця Єгипту?"
    options: ["Каїр", "Александрія", "Луксор", "Асуан"]
    answer: 1
    level: 1
    why: "Каїр — столиця Єгипту й найбільше місто Африки."
```

- `q` — саме питання;
- `options` — варіанти відповіді (від 2 до 10);
- `answer` — номер правильного варіанта (`1` — перший у списку);
- `level` — складність: `1`, `2` або `3`;
- `why` — коротке пояснення, можна не писати.

Правильну відповідь зручно писати першою — у чаті бот усе одно перемішує
варіанти. Щоб додати новий предмет, скопіюйте будь-який файл із папки,
змініть у ньому `name` та `emoji` і допишіть предмет у `subjects`
в `config.yaml`.

Після правок варто перевірити, що ніде не загубилася кома:
**Actions** → **Run workflow** → режим **check-quiz**. Бот перечитає всі
файли й напише в логах, чи все гаразд.

## 💬 Керування ботом прямо з групи

Не обов'язково заходити на GitHub. Усе головне можна змінити просто в чаті,
і це може зробити **будь-хто з групи**, не тільки власник.

Напишіть у групі команду (з косою рискою):

| Команда | Що покаже |
|---|---|
| `/menu` | головне меню з усіма налаштуваннями |
| `/temy` | список тем — вмикати й вимикати натисканням |
| `/chastota` | скільки новин на добу і о котрій |
| `/stat` | що подобається групі за голосами |

Далі просто тисніть на кнопки. Теми перемикаються одним дотиком:
✅ — тема увімкнена, ❌ — вимкнена.

### Кнопки 👍 та 👎 під новинами

Під кожною новиною є дві кнопки. Тисніть їх — і бот запам'ятає,
що вашій родині подобається.

- один голос від людини на одну новину;
- натиснули ще раз — голос скасовано;
- натиснули 👎 після 👍 — голос змінився.

Далі бот **сам підбирає новини** під ці вподобання: теми й сайти, які
отримують більше 👍, він показує частіше, а ті, що збирають 👎, — рідше.
Голоси за новини, старші за 30 днів, забуваються — щоб бот стежив за
теперішніми смаками, а не за торішніми.

Подивитись підсумок можна в `/stat`.

### ⏳ Чому кнопка спрацьовує не одразу

Кнопки працюють **миттєво** — їх обслуговує Netlify, який на відміну
від GitHub увімкнений завжди. Натиснули 👍 — лічильник змінився одразу.

GitHub лишається для головного: він раз на годину шле новини.
Якщо Netlify раптом ляже, новини все одно йтимуть — просто кнопки
на той час замовкнуть.

### Зміни з чату потрапляють у config.yaml

Коли хтось міняє тему чи кількість новин кнопками, бот акуратно
вписує це в `config.yaml` — рівно той рядок, що треба, не чіпаючи
пояснень. Тобто чат і файл на GitHub показують одне й те саме,
і правити можна звідки зручніше.

## Що ще корисно знати

### Затримка — це нормально

GitHub на безкоштовному тарифі будить бота коли заманеться — раз на
2-5 годин замість щогодини. Тому час стежить **Netlify**: коли настає
час розсилки, він сам просить GitHub запустити бота. Netlify працює
цілодобово й розклад виконує чесно.

Невелика затримка (5-15 хвилин) усе одно можлива — GitHub не миттєвий.
Це нормально.

Бот до цього готовий. Він не чекає точної хвилини, а щоразу дивиться,
які розсилки за сьогодні ще не відпрацьовані, і робить найсвіжішу.
Тому новини не зникають, навіть якщо GitHub довго спав.

Якщо бот проспав одразу кілька розсилок, він надішле тільки найсвіжішу,
а давніші тихо пропустить — щоб на родину не впало три порції новин поспіль.
Двічі за той самий час бот не шле ніколи.

### Де подивитися, чи все гаразд

Якщо новини раптом перестали приходити:

1. Відкрийте репозиторій на GitHub.
2. Вкладка **Actions** угорі.
3. Там список запусків. ✅ зелена галочка — усе добре, ❌ червоний хрестик — була помилка.
4. Натисніть на червоний запуск, далі на **send** — і побачите, що саме сталося.

### Запустити бота вручну

Вкладка **Actions** → зліва **Добрі новини і тести** → кнопка **Run workflow**.
Там можна вибрати:

- **schedule** — звичайний запуск (надішле, тільки якщо зараз час розсилки);
- **test** — надіслати одну новину прямо зараз, для перевірки;
- **dry-run** — просто показати новини в логах, нічого не надсилаючи;
- **quiz-test** — надіслати один шкільний тест прямо зараз;
- **quiz-dry-run** — показати тести в логах, нічого не надсилаючи;
- **check-quiz** — перевірити файли з питаннями на помилки.

### Про приватний репозиторій

Зараз репозиторій **публічний**, але це вже не обов'язково: відколи кнопки
обслуговує Netlify, GitHub вмикається лише раз на годину, і це спокійно
влазить у безкоштовний ліміт приватного репозиторію (2000 хвилин на місяць).

Щоб закрити його від сторонніх очей: **Settings** → донизу до
**Danger Zone** → **Change repository visibility** → **Make private**.
Міняти більше нічого не треба.

### Файл `state.json`

Це пам'ять бота: які новини він уже надсилав, як за них голосували
і які питання вже були в тестах.
Він створюється й оновлюється сам. Чіпати його не треба.

Заразом ці регулярні оновлення тримають бота живим: GitHub вимикає розклад
у репозиторіях, де довго нічого не відбувається.

## Переклад: два режими

У `config.yaml` є розділ `translation`:

```yaml
translation:
  provider: claude
```

- **`claude`** — гарний, людський переказ новини українською, плюс додаткова
  перевірка: якщо новина насправді сумна чи тривожна, бот її не надішле.
  Потрібен ключ Anthropic (коштує копійки на місяць).
- **`google`** — безкоштовно, без жодних ключів, але переклад машинний
  і місцями кострубатий, і без перевірки настрою новини.

Якщо стоїть `claude`, а ключа немає — бот **сам** перейде на `google`
і напише про це в логах. Тобто він працюватиме в будь-якому разі.

## Секрети (паролі бота)

Токени зберігаються **тільки** в секретах GitHub, ніколи в коді.
Дивитись їх можна тут: **Settings** → **Secrets and variables** → **Actions**.

| Назва | Для чого | Обов'язковий |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | пароль вашого бота від @BotFather | так |
| `TELEGRAM_CHAT_ID` | номер групи, куди слати (з мінусом) | так |
| `ANTHROPIC_API_KEY` | ключ для гарного перекладу | ні |
| `NETLIFY_URL` | адреса сайту з миттєвими кнопками | ні |
| `SYNC_SECRET` | пароль між GitHub і Netlify | ні |
| `TELEGRAM_WEBHOOK_SECRET` | пароль між Telegram і Netlify | ні |

А це — у змінних **Netlify** (Project configuration → Environment variables):

| Назва | Для чого |
|---|---|
| `TELEGRAM_BOT_TOKEN` | той самий токен бота |
| `TELEGRAM_CHAT_ID` | номер групи |
| `SYNC_SECRET` | той самий пароль, що й на GitHub |
| `TELEGRAM_WEBHOOK_SECRET` | той самий пароль, що й на GitHub |
| `GITHUB_TOKEN` | щоб будильник міг запускати бота |

## Для тих, кому цікаво, як воно влаштоване

| Файл | Що робить |
|---|---|
| `config.yaml` | усі налаштування |
| `bot.py` | головний скрипт: розклад, відбір, надсилання |
| `sources.py` | читає RSS, фільтрує новини, шукає картинки |
| `translator.py` | перекладає українською |
| `telegram_api.py` | надсилає пости й тести в Telegram |
| `quiz.py` | шкільні тести: вибір питань без повторів |
| `questions/` | самі питання, по файлу на предмет |
| `interact.py` | меню, кнопки, підрахунок голосів |
| `netlify/functions/bot.mjs` | миттєві кнопки: приймає натискання з Telegram |
| `netlify/functions/alarm.mjs` | будильник: нагадує GitHub, що час слати |
| `settings.py` | акуратна зміна config.yaml на прохання з чату |
| `state.json` | пам'ять: що вже надсилали, як голосували, які питання були |
| `.github/workflows/goodnews.yml` | розклад запусків на GitHub |

Запуск на своєму комп'ютері (не обов'язково):

```bash
pip install -r requirements.txt
python bot.py --dry-run --count 3   # показати новини, нічого не надсилати
python bot.py --test                # надіслати одну новину зараз
python bot.py --listen              # відповісти на кнопки й команди з групи
python bot.py                       # звичайний запуск за розкладом

python bot.py --quiz --dry-run      # показати тести, нічого не надсилати
python bot.py --quiz --test         # надіслати один тест зараз
python bot.py --quiz                # тести за розкладом
python bot.py --check-quiz          # перевірити файли з питаннями
```
