# 🌻 Бот добрих новин

Бот кілька разів на день сам надсилає у ваш Telegram-чат добрі новини
з усього світу — українською, з картинкою й посиланням на джерело.

Він працює на серверах GitHub, а **не** на вашому комп'ютері.
Тобто новини приходитимуть навіть тоді, коли у вас немає світла
чи інтернету, і комп'ютер узагалі вимкнений.

---

## Як змінити налаштування (з телефона теж)

Усе, що можна міняти, лежить в одному файлі — **`config.yaml`**.

1. Відкрийте цей репозиторій на GitHub.
2. Натисніть на файл **`config.yaml`**.
3. Натисніть **олівець** (✏️) угорі праворуч.
4. Змініть, що треба.
5. Прокрутіть униз і натисніть зелену кнопку **Commit changes**.

Усе. Наступного разу бот працюватиме вже за новими правилами.

> ⚠️ Одне важливе правило: **не міняйте пробіли на початку рядків.**
> Міняйте лише самі значення. Якщо файл випадково зламався —
> натисніть на нього, далі **History**, і поверніться до попередньої версії.

### Скільки новин на день

Знайдіть рядок:

```yaml
posts_per_day: 5
```

Поставте будь-яке число. Наприклад `3` — і на день приходитиме три новини.
Вони розділяться між часами розсилки якомога рівніше:
5 новин на 3 часи — це 2, 2 і 1.

### О котрій приходять новини

```yaml
send_times:
  - "09:00"
  - "14:00"
  - "20:00"
```

Час київський. Можна змінити години, додати ще один рядок або прибрати зайвий.
Головне — зберігати такий самий вигляд рядка: два пробіли, дефіс, пробіл і час у лапках.

### Які теми новин

Нижче у файлі є список тем. У кожної є рядок `enabled`:

```yaml
  - name: "Космос"
    enabled: false
```

- `true` — тема **увімкнена**, новини на цю тему приходитимуть;
- `false` — тема **вимкнена**.

Щоб увімкнути космос — просто замініть `false` на `true`.

Увімкнено від початку: наука і медицина, природа і тварини,
люди й добрі вчинки, технології та екологія.
Вимкнено: культура і спорт, космос.

### Стоп-слова

Список `blocked_keywords` — це слова-запобіжники. Якщо якесь із них є в новині,
бот її не надішле. Там уже є все про війну, політику, смерть і катастрофи.
Можна додавати свої слова — англійською, бо новини беруться з англомовних сайтів.

## Що ще корисно знати

### Затримка — це нормально

GitHub безкоштовно запускає бота приблизно раз на годину, але може затриматися
на **10–30 хвилин**, іноді трохи більше. Тобто новина о 09:00 може прийти
о 09:20. Це не поломка, так працює безкоштовний сервіс.

Бот це враховує: якщо GitHub спізнився менш ніж на ~1.5 години,
новини все одно прийдуть. Двічі за один і той самий час бот не надішле.

### Де подивитися, чи все гаразд

Якщо новини раптом перестали приходити:

1. Відкрийте репозиторій на GitHub.
2. Вкладка **Actions** угорі.
3. Там список запусків. ✅ зелена галочка — усе добре, ❌ червоний хрестик — була помилка.
4. Натисніть на червоний запуск, далі на **send** — і побачите, що саме сталося.

### Запустити бота вручну

Вкладка **Actions** → зліва **Добрі новини** → кнопка **Run workflow**.
Там можна вибрати:

- **schedule** — звичайний запуск (надішле, тільки якщо зараз час розсилки);
- **test** — надіслати одну новину прямо зараз, для перевірки;
- **dry-run** — просто показати новини в логах, нічого не надсилаючи.

### Файл `state.json`

Це пам'ять бота: які новини він уже надсилав, щоб не повторюватись.
Він створюється й оновлюється сам. Чіпати його не треба.

Заразом ці регулярні оновлення тримають бота живим: GitHub вимикає розклад
у репозиторіях, де довго нічого не відбувається.

## Переклад: два режими

У `config.yaml` є розділ `translation`:

```yaml
translation:
  provider: claude
```

- **`claude`** — гарний, людський переказ новини українською, плюс додаткова
  перевірка: якщо новина насправді сумна чи тривожна, бот її не надішле.
  Потрібен ключ Anthropic (коштує копійки на місяць).
- **`google`** — безкоштовно, без жодних ключів, але переклад машинний
  і місцями кострубатий, і без перевірки настрою новини.

Якщо стоїть `claude`, а ключа немає — бот **сам** перейде на `google`
і напише про це в логах. Тобто він працюватиме в будь-якому разі.

## Секрети (паролі бота)

Токени зберігаються **тільки** в секретах GitHub, ніколи в коді.
Дивитись їх можна тут: **Settings** → **Secrets and variables** → **Actions**.

| Назва | Для чого | Обов'язковий |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | пароль вашого бота від @BotFather | так |
| `TELEGRAM_CHAT_ID` | номер групи, куди слати (з мінусом) | так |
| `ANTHROPIC_API_KEY` | ключ для гарного перекладу | ні |

## Для тих, кому цікаво, як воно влаштоване

| Файл | Що робить |
|---|---|
| `config.yaml` | усі налаштування |
| `bot.py` | головний скрипт: розклад, відбір, надсилання |
| `sources.py` | читає RSS, фільтрує новини, шукає картинки |
| `translator.py` | перекладає українською |
| `telegram_api.py` | надсилає пости в Telegram |
| `state.json` | пам'ять: що вже надсилали |
| `.github/workflows/goodnews.yml` | розклад запусків на GitHub |

Запуск на своєму комп'ютері (не обов'язково):

```bash
pip install -r requirements.txt
python bot.py --dry-run --count 3   # показати новини, нічого не надсилати
python bot.py --test                # надіслати одну новину зараз
python bot.py                       # звичайний запуск за розкладом
```
